# Физические цепи: Physicalist 0.9.0

В творческой вкладке Physicalist появился создатель физических цепей.
ПКМ выбирает первую точку, следующий ПКМ — вторую.
Shift + ПКМ по воздуху выбирает самого игрока; затем можно нажать ПКМ по другу.
Shift + ПКМ по блоку отменяет выбор. ПКМ ножницами по звену разрезает соединение.

Можно привязывать блоки, игроков, мобов, предметы, транспорт и физические объекты.
Цепь состоит из отдельных звеньев на шарнирах, провисает и сталкивается с миром.
Игрок может толкать её телом. Натяжение передаётся игрокам: можно перетягивать друга.
Разрезанные звенья остаются физическими. Для конструкций Sable/Aeronautics точка
крепления следует за поворотом конструкции, а натяжение передаётся как сила.
Если объект крепления не загружен, цепь приостанавливается до его возвращения.

Длина ограничена 32 блоками, звеньев не больше 65 на одну цепь.
Регдолл получил более свободные суставы и исправленную передачу движения конечностей.
У ассемблированных блоков убраны ванильные толчки рамкой сущности, исправлены пустые
формы на стыках и введено сглаживание целого поворота. Нативный движок — Rapier3D.
В Air War 5.13 исправлен сетевой удар по ракете и добавлено исключение пускового
блока для Вихря до выхода из установки. Остальные препятствия сохраняют коллизию.
